# Interactive Org Chart Engine & Admin Portal

A web application featuring an interactive organizational chart tree engine and a user administration control panel, built using Django, HTML, CSS, and JavaScript.

---

## Key Features

- **Interactive Org Chart Engine:** Dynamic tree visualization and layout mapping for organizational structures.
- **Admin User Control Panel:**
  - **Employee Management:** Add new corporate employees with automated password generation.
  - **Profile Management:** Modify existing corporate employee profiles.
  - **Account Deletion:** Permanently delete corporate accounts.
- **Authentication & Access Control:** Secure user login and portal dashboard navigation.
